What it does

Copy as Markdown is a free bookmarklet that converts the text you select on a web page into Markdown and puts it on your clipboard. It saves the round trip of copying HTML, pasting it into a converter and copying the result again. Paste it straight into Obsidian, Notion, a GitHub issue or README, your notes app, or an AI chat.

What gets converted

  • Headings, bold, italic and strikethrough
  • Links and images, with relative URLs turned into full ones
  • Bulleted, numbered, nested and checkbox lists
  • Tables, as GitHub-flavored Markdown tables
  • Inline code and code blocks, keeping the language
  • Block quotes and line breaks

Partial selections keep their context: select two list items and you get a list, select a few table rows and you get a table.

How it works

The conversion runs entirely in your browser, using a compact port of the Turndown HTML-to-Markdown converter. Nothing is sent anywhere, there's no extension to install, and it works on sites with strict security policies because it doesn't load any outside scripts. It works in Chrome, Edge, Firefox, Brave and other desktop browsers that support bookmarklets. It can't read apps that draw text on a canvas, such as Google Docs.
